🎯 Plinko Game (Java Project)

This project is a **Plinko Game** developed in **Java**, inspired by the popular game show “The Price Is Right.” The game simulates dropping a puck into a pegged board where it bounces randomly before landing in a slot that determines the player’s score or reward.

🕹️ Features

* Interactive **graphical interface** using Java Swing (or mention JavaFX if you used it)
* Realistic **randomized puck movement** and collision behavior
* Dynamic **score calculation** based on the final slot
* Option to **drop multiple pucks** and view cumulative scores
* Simple, lightweight, and beginner-friendly Java implementation

💻 **Technologies Used**

* **Language:** Java
* **IDE:** (e.g., IntelliJ IDEA / Eclipse / NetBeans)
* **Libraries:** (e.g., Java Swing / AWT / JavaFX)

🚀 **How to Run**

1. Clone this repository:

   ```bash
   git clone https://github.com/romit581/Plinko-Game.git
   ```
2. Open the project in your Java IDE.
3. Compile and run the `Main.java` file.
4. Enjoy the game!
